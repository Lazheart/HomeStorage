# HomeStorage


**HomeStorage** es un proyecto de Código Abierto que busca facilitar la transferencia de
imágenes, videos , documentos y archivos. Desde una plataforma centralizada, escalable y altamente configurable. 

El proyecto se encuentra en una etapa temprana de desarrollo, se busca crear una API RESTfull que cubra los siguientes puntos:

1. Autenticación de usuarios.
2. Control de permisos de Lectura y Escritura.
3. Limites de almacenamiento y carga para cada usuario.

## Estructura del Proyecto

## Stack Tecnologico

Como parte de un ejercicio y apoyando la inciativa de la Rust Foundation de fomentar el uso de **Rust** en el desarrollo de sistemas de bajo nivel y aplicaciones de alto rendimiento.

Este proyecto integra rust como su principal tecnologia, permitiendo una mejor optimizacion de recursos y seguridad.


## Empaquetado y Distribucion

Se plantea distribuir la aplicacion en contenedores de Docker, permitiendo una facil escalabilidad y despliegue.

A su vez una vez consolidado el proyecto se desarrollara una arquitectura  serverless , intengrando servicios de Amazon Web Services , Azure y Oracle Cloud.
